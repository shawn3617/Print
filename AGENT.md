# Контекст проекта: AutoCAD Batch PDF Plotter

## Роль

## Описание проекта
Десктопное приложение для пакетной печати чертежей в PDF из пространства модели (Model Space) AutoCAD. 
Программа должна сканировать Model Space, находить рамки чертежей различных типов, извлекать из них номер листа для правильной сортировки/именования файлов и отправлять их на печать (встроенным PDF-принтером AutoCAD, например, "DWG To PDF.pc3").

## Алгоритмы распознавания форматов (рамок)
Приложение должно поддерживать три типа рамок:
1. **Объекты СПДС GraphiCS**: поиск специфических объектов (или блоков) СПДС, извлечение габаритов рамки и параметра "Номер листа".
2. **Полилиния в определенном стиле (разбитый штамп)**: поиск замкнутых полилиний на заданном слое/с заданным стилем, определяющих габариты листа. Поскольку штамп разбит, номер листа должен определяться пространственным поиском (поиск объекта Text/MText по заданным координатам относительно правого нижнего угла габарита полилинии).
3. **Пользовательские блоки форматов**: поиск вхождений блоков (BlockReference) по имени. Определение габаритов по BoundingBox блока, чтение номера листа из атрибутов (Attributes) блока.

## Архитектурные требования (SOLID)
- Строгое разделение логики (MVC/MVVM). 
- Отдельный модуль для UI (PySide6).
- Отдельный модуль-коннектор для работы с AutoCAD COM API (подключение к активному процессу, чтение объектов, запуск печати).
- Отдельный модуль парсинга (логика пространственного поиска текста внутри полилиний, чтение атрибутов блоков).
- Использование паттернов проектирования (например, Strategy для разных алгоритмов поиска рамок).

1. **Язык общения**: Строго русский.
2. **Микро-шаги (TDD подход)**: НИКОГДА не пиши весь код приложения сразу. Двигайся максимально мелкими, логически завершенными шагами.
3. **Тестирование**: После написания каждого блока кода (например, коннектора к AutoCAD или функции поиска полилиний), останавливайся и давай мне инструкцию, как это протестировать. Жди моего подтверждения об успешном тесте, прежде чем переходить к следующему шагу.
4. **Безопасность**: Код должен корректно обрабатывать исключения (например, если AutoCAD не запущен, если чертеж пуст, если COM-сервер не отвечает).
