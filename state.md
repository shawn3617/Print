## Проект: AutoCAD Batch PDF Plotter (PrintPDF)

Десктопное приложение на Python (Qt-интерфейс, `ui/main_window.py`) для пакетной печати чертежей AutoCAD в PDF:
выбор папки с DWG → поиск рамок (СПДС, блоки, полилинии) → таблица листов (номер, наименование, формат) → печать в один многостраничный PDF или по файлу на лист.

Работает **снаружи AutoCAD через COM** (`win32com`) + быстрые LISP-экспортёры рамок.

---

## 1. Запуск, сборка, окружение

- **Запуск из VS Code:** `python -m ui.main_window` (из корня проекта, окружение `.venv`).
- **Сборка:** `build.bat` в корне → готовая программа в `dist\PrintPDF\` (`PrintPDF.exe` + папка `_internal`, переносить целиком).
  - Точка входа для сборки — `run_app.py` (запускает `ui.main_window` как модуль).
  - Режим `--onedir` (не один exe: один exe медленно стартует и раздражает антивирусы).
  - В сборку кладутся: `core\lisp`, `plotters`, `config.json`, иконка.
  - Сейчас собирается **с консолью** (для тестирования коллегами). Для релиза — добавить `--windowed`.
  - Старые `.spec` не используются (в `.gitignore`); `build\` и `dist\` — тоже в `.gitignore`.
- **AutoCAD:** 2021 (R24.0) и 2024 (R24.3), русские. Рамки СПДС требуют установленного СПДС GraphiCS.
- **Плоттеры:** у каждой версии AutoCAD свои папки (`%APPDATA%\Autodesk\AutoCAD <год>\<R>\rus\Plotters` и `...\Plotters\PMP Files`) — перенастроено, каждая версия берёт свои.
- **Git/GitHub:** репозиторий на GitHub, работа с двух компьютеров (дом/работа). Перед работой — «Синхронизировать», после — «Фиксация» + «Синхронизировать».

## 2. Архитектура

### core/
- **`autocad_connector.py`** — подключение к AutoCAD, открытие/поиск/активация/закрытие чертежей.
  - `_retry_busy(func)` — повтор, пока AutoCAD занят. Повторяет `AttributeError` (в exe занятость приходит как `'<unknown>.Count'`, `'Open.ModelSpace'`, `'Item.ModelSpace'`) и COM-ошибки «занят» (`RPC_E_CALL_REJECTED`, `RPC_E_SERVERCALL_RETRYLATER`, `RPC_E_DISCONNECTED`). Настоящие ошибки («Неверный ввод») сразу наверх.
  - `open_document` после `Documents.Open` ждёт готовности AutoCAD и берёт документ заново из `Documents` по пути (объект из `Open` в exe бывает «пустым»).
- **`com_utils.py`** — старый `com_retry` (не ловит `AttributeError`; в печати заменён на `_retry_busy`).
- **`printer.py`** — `BatchPrinter.print_frames`:
  - если активного чертежа нет (печать из папки) — открывает DWG первой рамки;
  - открытые для печати чертежи **остаются открытыми** (`close_opened_docs=False` по умолчанию);
  - `_apply_printer` проверяет, что плоттер есть в AutoCAD, иначе понятная ошибка со списком доступных;
  - подбор бумаги по формату рамки (`media_map`), при отсутствии — резервный формат с предупреждением в консоли;
  - `BACKGROUNDPLOT=0` на время печати, восстановление до закрытия чертежей;
  - склейка PDF через `pypdf`.
- **`plotter_installer.py`** — ставит свои плоттеры из `plotters\<год>\` (pc3 + pmp) **только в тот AutoCAD, к которому подключена программа**, в папки пользователя. Копирует, если нет или отличается; старый файл → `.bak`. Вызывается один раз за запуск (при получении списка принтеров и перед печатью).
- **`resource_utils.py`** — `get_resource_path` (пути к ресурсам в обычном запуске и в exe).
- **`config_manager.py`, `exporter.py`, `scanner.py`, `models.py`** — настройки, экспорт реестра в Excel/CSV, обход папок, модели (`Frame`, `ALL_FORMATS`, `detect_paper_format`).

### core/lisp/ (кодировка **Windows-1251**, не пересохранять в UTF-8!)
- **`spds_export.lsp`** — `(sht-export-spds "файл.json")`, рамки `SPDSFORMAT` в модели. Логика полей — по `SHEET_FROM_SPDS` из SHEETS.lsp (проект PYLON):
  - форма определяется как в SHEETS: есть кириллические имена полей (`Масса`, `Масштаб`, `Лист`) → форма 4; нет `Author` → 6; признаки формы 5; иначе 3;
  - **номер:** форма 4 — `Лист` (если кодировка не совпала — самое короткое кириллическое имя поля), остальные — `Sheet`; `PageNumber` — только запасной;
  - **наименование:** форма 3 — `Drawing type`; форма 4 — `DrawingName1` → `ComplexName` → `Drawing type`; форма 5 — `DrawingName1`; форма 6 — нет;
  - в JSON также `form` и `fields` (все поля рамки) — для отладки.
- **`block_export.lsp`** — `(sht-export-blocks "файл.json" "маски" "теги_номера" "теги_названия")`, блоки-рамки по маске имени и тегам атрибутов.

### parsers/
- **`base_parser.py`** — общий запуск LISP: `_run_lisp_export` (путь к лиспу с прямыми слэшами — иначе в exe `load` ломается; активация чертежа и ожидание AutoCAD перед `SendCommand`; таймаут 20 с; чтение JSON в cp1251).
- **`spds_parser.py`**, **`block_parser.py`** — LISP-экспорт, при неудаче COM-перебор (он номера/наименования СПДС не читает — `Unknown`).
- **`polyline_parser.py`** — рамки-полилинии на слое `0000_Формат` (разбитые рамки):
  - объекты слоя — одним набором выбора (быстро), габариты текстов считаются один раз;
  - формат и масштаб — по совпадению с форматами ГОСТ (внешняя граница или внутренняя рамка с полями 20/5 мм);
  - неоднозначность (A2 М1:100 = A4 М1:200) решается: парная внутренняя рамка → заголовки «Стадия/Лист/Листов» на местах → масштаб типа линий;
  - внутренняя рамка внутри внешней — тот же лист (не дубль); печать по внешней границе;
  - номер — графа «Лист», наименование — графа 4 (нижняя строка средней колонки) формы 3; запасной поиск номера рядом с надписью «Лист».

### ui/
- **`main_window.py`** — таблица листов (drag-and-drop, поиск, фильтр по форматам, выбор отфильтрованных), настройки печати, экспорт реестра.

### plotters/
- `plotters\2024\PDF_ГОСТ.pc3`, `PDF_ГОСТ.pmp` — свой плоттер с настроенными форматами (копия DWG To PDF).
- `plotters\2021\` — **ещё не сделан** (pc3 из 2024 в 2021 не читается).

## 3. Принятые решения (не переделывать без причины)

1. Чертежи, открытые программой, после печати **не закрываются** (как в REVERS) — меньше сбоев COM, повторная печать быстрее.
2. Плоттеры — **по версиям AutoCAD**, своё имя (`PDF_ГОСТ`), чужой `DWG To PDF.pc3` не трогаем.
3. Сборка — **папка**, не один exe; установщик (Inno Setup) — позже, когда понадобится.
4. LISP-файлы — **cp1251**.
5. Наименование/номер СПДС — **строго по форме штампа**, без «угадывания» по спискам полей.
6. Везде, где обращение к AutoCAD, — `_retry_busy`, а не `com_retry`.

## 5. Известные ограничения и проблемы

- Рамка, разбитая до **отрезков** (без полилиний), не находится.
- Разбитый блок с атрибутами через EXPLODE теряет значения (остаются теги) — нужен BURST.
- COM-перебор СПДС (запасной путь) не читает номер и наименование.
- Работа через COM снаружи AutoCAD в принципе чувствительна к занятости AutoCAD; основные места защищены, но новые ошибки вида `<unknown>.X` / `Open.X` / `Item.X` лечатся тем же `_retry_busy`.
- При большой папке все чертежи остаются открытыми — возможна нехватка памяти (нет кнопки «Закрыть открытые программой»).
- Резервный формат по умолчанию B5 — лучше A1/A3.
