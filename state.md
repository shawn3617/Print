# Текущее состояние проекта (State)

## Проект: AutoCAD Batch PDF Plotter
Десктопное приложение (Python / PySide6) для автоматического сканирования чертежей AutoCAD в пространстве модели (Model Space), определения форматов рамок (СПДС, Блоки, Полилинии), сортировки/ручного упорядочивания листов и пакетной печати в PDF (как в отдельные файлы, так и в один общий многостраничный документ).

---

## 1. Выполненные пункты

- [x] **Архитектура приложения**:
  - `core/autocad_connector.py` — подключение к активному процессу AutoCAD через COM API (`win32com`).
  - `core/models.py` — структуры данных `Frame`, ГОСТ форматы бумаги (А0–А4, расширенные AxN), алгоритм `detect_paper_format`.
  - `core/scanner.py` — агрегатор сканирования, запуск всех парсеров, гармонизация масштабов чертежа.
  - `core/printer.py` — пакетная печать через AutoCAD `PlotToFile`, объединение PDF через `pypdf`.
  - `ui/main_window.py` — темный интерфейс на PySide6.

- [x] **Парсеры рамок**:
  - `SPDSParser` (`parsers/spds_parser.py`) — высокоскоростной сбор рамок через нативный LISP-мост `core/lisp/spds_export.lsp` (логика `SHEETS.lsp`): мгновенный C++ сбор через `(ssget "_X" '((0 . "SPDSFORMAT,*MCS*,*SPDB*")))`, прямое чтение групп DXF 301, BoundingBox и санитизация спецсимволов (`\U+2205` / `⌀`). Время поиска снижено с 24+ секунд до 0.09–0.15 сек, устранены ошибки `Item.GetVariable` и `RPC_E_CALL_REJECTED`.
  - `BlockParser` (`parsers/block_parser.py`) — поиск блоков по маске (например `SHT_*`, `Формат*`), быстрая проверка определений в `doc.Blocks` (0.002 сек) исключает холостой перебор объектов, чтение атрибутов (`SHEET`, `TITLE`), учет масштаба `XScaleFactor`.
  - `PolylineParser` (`parsers/polyline_parser.py`) — быстрая пре-проверка таблицы слоев `doc.Layers` (0.001 сек), поиск замкнутых полилиний на заданном слое, авторасчет масштаба, пространственный поиск текстов в зоне штампа.
  - `DocumentScanner` (`core/scanner.py`) — приоритет быстрого LISP-парсера СПДС и прерывание цикла при обнаружении рамок без холостых переборов.

- [x] **Алгоритм определения форматов бумаги**:
  - Устранена коллизия форматов А-серии (А4 vs А2 при масштабе 1:100).
  - Приоритет стандартных масштабов по ГОСТ 2.302-68 (в первую очередь 1:100, затем 1:50, 1:1).
  - Сквозное согласование масштаба в чертеже (доминирующий масштаб проекта).

- [x] **Печать в PDF и интеграция с PDF-просмотрщиком (PDF-XChange)**:
  - Автоматический патчинг PC3-файлов (`View_New_File = FALSE`), исключающий всплывание десятков окон/вкладок при пакетной печати.
  - Опция «Открыть результат» — автоматическое открытие объединенного PDF в PDF-XChange или папки с файлами.
  - Обработка `PermissionError` с понятным сообщением, если итоговый PDF уже открыт в просмотрщике.

- [x] **Ручное изменение порядка листов**:
  - Кнопки «▲ Вверх (Ctrl+↑)» и «▼ Вниз (Ctrl+↓)».
  - Перетаскивание строк мышкой (Drag & Drop) через кастомный `ReorderableTableWidget` с `QDrag` + `CopyAction` (защита от удаления строк Qt).
  - Кнопки быстрого выбора «Выбрать все» / «Снять все».
  - Кнопка «По номерам» для быстрого сброса к стандартной сортировке по номерам листов.

- [x] **Подсветка и центрирование рамки в AutoCAD**:
  - Метод `zoom_window` и `highlight_object` в `core/autocad_connector.py`.
  - Сохранение `handle` рамки в модели `Frame` во всех парсерах (СПДС, Блоки, Полилинии).
  - Интеграция в интерфейс `ui/main_window.py`: центрирование и подсветка рамки при клике на строку или навигации стрелками.
  - Опция (чекбокс) «Подсветка в AutoCAD» и кнопка «В AutoCAD» (без эмодзи).

- [x] **Сохранение и загрузка настроек (config.json)**:
  - Модуль `core/config_manager.py` — чтение, запись и слияние с дефолтными значениями, устойчивость к некорректным данным.
  - Сохранение параметров: выбранный принтер, стиль печати, резервный формат, режим объединения ("В один файл (PDF)" / "В отдельные файлы"), чекбокс «Открыть результат», чекбокс «Подсветка в AutoCAD».
  - Автоматическое сохранение при изменении параметров пользователем и при закрытии окна.
  - Автоматическое восстановление параметров при запуске приложения и при подключении к AutoCAD.

- [x] **Поддержка пространства листов (Layouts)**:
  - `core/models.py` — функция `detect_format_from_media_name` для распознавания форматов ГОСТ из названий бумаги плоттера.
  - `core/scanner.py` — метод `scan_layouts(doc)`: считывание вкладок пространства листа (без Model), строгая сортировка по порядку вкладок `TabOrder`, автоопределение формата и номера листа.
  - `core/autocad_connector.py` — метод `activate_layout(layout_name)`, обновление `show_frame` для переключения активной вкладки при выборе строки таблицы или нажатии «В AutoCAD».
  - `core/printer.py`:
    - Поддержка печати листов через `PlotType = 5` (`acLayout`), исключены недопустимые для `acLayout` параметры (`CenterPlot`, `StandardScale = acScaleToFit`).
    - Функция `com_retry` с автоматическими повторными попытками при занятости AutoCAD (`RPC_E_CALL_REJECTED` / `-2147418111` / `0x80010001`).
    - Пауза на регенерацию Paper Space перед отправкой на печать и восстановление исходно открытого листа.
  - `ui/main_window.py` — выбор источника («Модель (Model Space)» / «Листы (Layouts)»), динамическая смена надписи кнопки («Найти рамки» / «Загрузить листы»), сохранение и восстановление параметра в `config.json`.
  - Автоматические тесты: `test_layouts.py`.

- [x] **Пакетная печать списка DWG-файлов (Batch DWG)**:
  - `core/models.py` — расширение структуры `Frame`: поля `dwg_path` (полный путь к чертежу) и `dwg_name` (имя файла).
  - `core/autocad_connector.py` — функции управления чертежами: `open_document(filepath, read_only=True)`, `close_document(doc, save_changes=False)`, `find_open_document`, `get_open_documents`, `activate_document`. Автопереключение чертежа в `show_frame`.
  - `core/scanner.py` — метод `scan_files(connector, file_paths, source_mode, progress_callback, is_cancelled)`: последовательное пакетное сканирование файлов с отслеживанием прогресса, автозакрытием фоновых документов и сохранением открытых чертежей пользователя.
  - `core/printer.py` — печать рамок из нескольких чертежей: автоматическое переключение активного документа при печати, корректное закрытие временных документов в блоке `finally`, предотвращение коллизий имен файлов при раздельной печати (`[ИмяЧертежа] Лист N - [ИмяЛиста].pdf`).
  - `ui/main_window.py`:
    - Панель пакетной обработки: кнопки «+ Добавить DWG...», «+ Папка с DWG...», «Очистить список».
    - Поддержка Drag & Drop: перетаскивание файлов `.dwg` и папок прямо в главное окно или таблицу из Проводника Windows.
    - Новая колонка таблицы «Чертеж» (6 колонок).
    - Естественная сквозная сортировка номеров листов (`natural_sheet_sort_key`): корректный порядок для составных и дробных номеров (например, лист `4а` и `4.1` идут строго после листа `4` и перед листом `5`, а лист `10` идет после `9`). Сквозной порядок работает как при добавлении новых файлов, так и по кнопке «По номерам».
    - Диалог прогресса сканирования с возможностью отмены.
  - Автоматические тесты: `test_batch_connector.py`, `test_batch_scanner.py`, `test_batch_printer.py`, `test_batch_ui.py`, `test_natural_sort.py`.

## 2. Что необходимо протестировать пользователю (To Test)

- [ ] **Пакетная обработка нескольких DWG-файлов**:
  1. Запустить приложение командой:
     ```bash
     python -m ui.main_window
     ```
  2. Проверить сортировку составных номеров листов: добавить чертежи с листами вида `4`, `4а`, `4.1`, `4б`, `5`. Убедиться, что `4а` и `4.1` располагаются сразу за листом `4` перед листом `5`, а не улетают в конец списка.
  3. Проверить сквозную сортировку: добавить сначала чертеж с листами 6-10, затем чертеж с листами 1-5. Убедиться, что в таблице листы автоматически выстроились в общий непрерывный список 1, 2, ..., 10.
  4. Проверить сброс сортировки кнопкой **«По номерам»** после ручного перемещения строк.
  5. Проверить добавление файлов Drag & Drop перетаскиванием файлов `.dwg` из Проводника Windows.
  6. Проверить добавление всех чертежей из папки через кнопку **«+ Папка с DWG...»**.
  7. Проверить кнопку **«Очистить список»**.
  8. Проверить навигацию: при клике на строку чертежа или нажатии **«В AutoCAD»** программа автоматически активирует нужный DWG в AutoCAD и центрирует рамку/лист.
  9. Запустить печать в режиме **«В один файл (PDF)»** — проверить, что листы из всех чертежей объединились в один документ в порядке строк таблицы.
  10. Запустить печать в режиме **«В отдельные файлы»** — проверить, что файлы сохранились без взаимного перезаписывания с префиксами `[ИмяЧертежа] Лист N...`.

- [ ] **Быстрый поиск СПДС-рамок через LISP-мост (без зависаний и COM-ошибок)**:
  1. Запустить приложение командой:
     ```bash
     python -m ui.main_window
     ```
  2. В активном чертеже с СПДС-рамками (или добавив его через «+ Добавить DWG...») нажать кнопку **«Найти рамки»**.
  3. Убедиться, что:
     - Поиск отрабатывает практически мгновенно (~0.1 сек).
     - Все листы СПДС находятся без пропусков (100%).
     - В консоли отсутствуют ошибки `Item.GetVariable` и `RPC_E_CALL_REJECTED` (`-2147418111`).
     - Корректно определяются номера листов, форматы (в т.ч. удлиненные вроде `A4x3`, `A2x3`) и многострочные названия со спецсимволами.
     - Подсветка и центрирование рамки («В AutoCAD») корректно работают для найденных листов.
