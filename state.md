# Текущее состояние проекта (State)

## Проект: AutoCAD Batch PDF Plotter
Десктопное приложение (Python / PySide6) для пакетной печати чертежей AutoCAD из пространства модели (Model Space), поиска рамок (СПДС, Блоки, Полилинии), фильтрации/сортировки и экспорта в единый или многостраничный PDF.

---

## 1. Архитектура и ключевые модули

- **Ядро подключения (`core/autocad_connector.py`, `core/com_utils.py`)**:
  - Подключение к `AutoCAD.Application` через `win32com.client`.
  - Защита COM-вызовов от занятости AutoCAD (`RPC_E_CALL_REJECTED`, `-2147418111`) через декоратор `com_retry`.
  - Управление документами (`open_document`, `close_document`, `find_open_document`, `activate_document`).

- **Модуль экспорта реестра (`core/exporter.py`)**:
  - Выгрузка списка листов в Excel (`.xlsx`) со стилизацией через `openpyxl`.
  - Выгрузка списка листов в CSV (`utf-8-sig`).

- **Парсеры рамок (`parsers/`)**:
  - `spds_parser.py`: Нативный AutoLISP-экспорт (`core/lisp/spds_export.lsp`) за ~0.1 сек. Поддержка всех типов СПДС-штампов (ГОСТ 21.101-97, 21.101-2020, формы 3, 4, 5, 6, многострочные поля `DrawingName1..9`, `Name 1..9`, `Наименование 1..9`, учет русскоязычных ключей `Лист`, `Обозначение` и защита от пустых полей `Sheet`/`Drawing type`). Геометрический fallback габаритов при нулевом BoundingBox.
  - `block_parser.py`: Нативный AutoLISP-экспорт (`core/lisp/block_export.lsp`) за ~0.05 сек. Мгновенное чтение блоков, вложенных блоков и динамических атрибутов.
  - `polyline_parser.py`: Поиск рамок по замкнутым прямоугольным полилиниям.

- **Пользовательский интерфейс (`ui/main_window.py`)**:
  - Таблица листов с Drag-and-Drop перетаскиванием строк.
  - Живой поиск по номеру/названию листа и фильтр по форматам (с динамическим подсчетом количества).
  - Интеллектуальный выбор ("Выбрать все отфильтрованные", "Снять со всех отфильтрованных").
  - Блокировка Drag-and-Drop при активном фильтре для сохранения естественного порядка.
  - Экспорт реестра листов в Excel / CSV.

- **Сборка приложения**:
  - Автономный исполняемый файл `dist/AutoCAD_Batch_Print.exe`, собранный через PyInstaller (`AutoCAD_Batch_Print.spec`).
  - Все необходимые LISP-скрипты запакованы внутрь дистрибутива.
