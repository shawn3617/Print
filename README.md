# PrintPDF — пакетная печать чертежей AutoCAD в PDF

Программа для Windows (Python + Qt). Находит рамки листов в чертежах AutoCAD и печатает
их в PDF: один многостраничный файл на комплект или по файлу на лист.

Работает снаружи AutoCAD через COM (pywin32). Рамки читают быстрые LISP-экспортёры.
Образец, на который ориентировалась программа, — REVERS.

Автор — Артём, инженер-проектировщик ПГС. Код написан с помощью ИИ.

## Что умеет

- Сканирует активный чертёж или папку с DWG.
- Находит рамки: СПДС GraphiCS (`SPDSFORMAT`), блоки-рамки (по маске имени и атрибутам),
  разбитые рамки-полилинии на слое `0000_Формат`, рамки на листах (Layouts).
- Читает из штампа номер, наименование, шифр, объект и здание. Номер и наименование
  берутся строго по форме штампа: формы 3, 4, 5, 6 ГОСТ Р 21.101.
- Определяет формат (A4…A0 и кратные) и масштаб. Титульный лист ставит первым.
- Ставит свой плоттер `PDF_ГОСТ` отдельно для AutoCAD 2021 и 2024 (`plotters/<год>/`).
- Экспортирует реестр листов в Excel и CSV, обновляется сама через GitHub Releases.

Поддерживаются русские AutoCAD 2021 (R24.0) и 2024 (R24.3).

## Запуск из исходников (Windows, папка проекта `d:\Projects\Print`)

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m ui.main_window
```

Запускать именно `python -m ui.main_window` из корня проекта, не `python ui/main_window.py`.

## Тесты

```powershell
.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py"
```

Более 320 тестов, AutoCAD для них не нужен: COM подменяется. Их же сам запускает
GitHub Actions на каждый push (вкладка **Actions**). Красный крестик там означает,
что выпускать версию нельзя.

## Сборка и выпуск версии

1. Версия и дата меняются только в `core/version.py`.
2. `build.bat` компилирует LISP в `.fas` и собирает программу PyInstaller в `dist\PrintPDF\`.
   Затем он делает `PrintPDF_vX.Y.Z_Portable.zip` и, если установлен Inno Setup 6,
   установщик `PrintPDF_Setup_vX.Y.Z.exe`.
3. На GitHub: Releases → новый релиз с тегом `vX.Y.Z`. Оба файла прикладываются
   без переименования, «Pre-release» не ставится. Иначе автообновление их не найдёт.

Подробно — `state.md`, раздел 7.2.

## Файлы

| Папка / файл | Что там |
|---|---|
| `ui/` | окна: главное, «О программе», справка (F1), обновление, темы |
| `core/` | связь с AutoCAD, печать, сканирование, плоттеры, настройки, обновления, версия |
| `core/lisp/` | `spds_export.lsp`, `block_export.lsp`. **Кодировка Windows-1251, не пересохранять в UTF-8** |
| `parsers/` | разбор рамок: СПДС, блоки, полилинии |
| `plotters/2021`, `plotters/2024` | плоттер `PDF_ГОСТ` (.pc3 + .pmp) для каждой версии AutoCAD |
| `scripts/compile_lisp.py` | компиляция LISP в `.fas` |
| `installer/setup.iss` | установщик Inno Setup |
| `diagnose_*.py`, `inspect_objects.py` | разбор чертежа при отладке |
| `config.json` | настройки по умолчанию |

## Как продолжить работу с другим ИИ

1. Первым сообщением: «Прочитай `AGENT.md` и `state.md` (сначала раздел 7). Ничего не
   меняй, пока не прогонишь тесты».
2. Ближайшая задача — `state.md`, п. 7.4.1: ложные форматы A4x2…A1x2.
   Версия 1.3.3 готова к выпуску (п. 7.3).
3. После каждой правки — тесты, потом проверка в AutoCAD, причём и в собранном exe.

Codex и Cline читают `AGENTS.md` (с буквой S). Чтобы они нашли правила сами,
можно скопировать `AGENT.md` в `AGENTS.md`. Иначе просто укажите файл в первом сообщении.
